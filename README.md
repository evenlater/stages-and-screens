# stages-and-screens

Hugo site for *Stages & Screens*, Darryl Cater's essays on theater, opera,
film, and books. Forked from the *Ideational Evolution* Hugo template —
same layout, structure, and typography; only the accent colors, site
copy, and category tags changed. See `static/css/main.css` for the color
mapping notes.

Build: `hugo --gc --minify` (Hugo v0.161.1 extended). Deploys via Netlify
(see `netlify.toml`).
